Introduction

Calculus is the study of rates of change. All of calculus is built on the first module: limits.

Below is a short summary of the ten modules we cover in AP Calculus BC. None of this should make sense.

1. Limits
In this module, we examine how functions behave as they approach a specific point.

2, 3, 4, and 5. Differentiation
Using limits, we will find derivatives. Derivatives represent the slope of a function at each point. Finding derivatives is called differentiation.

6 and 8. Integration
In the previous modules, we start with functions and find their slopes at each point. In this module, we start with the slopes at each point, and we find the functions. This is called integration. The functions created by integration are called integrals.

7. Differential Equations
Differential equations are equations which use functions and their derivatives. For example, if

f(x)
is a function, and
f'(x)
is its derivative, then
f(x)+f'(x)=x
is a differential equation.

9. Parametric Equations, Polar Coordinates, and Vector-Valued Functions
We represent functions by having the input and output be the horizontal and vertical position of a point on a graph. There are other ways to graph functions, and these new ways allow for new functions. This is an introduction to those new functions.

10. Infinite Sequences and Series
Sequences are lists of numbers. Series are the sums of series. The sequences we are studying will usually be infinitely long.
