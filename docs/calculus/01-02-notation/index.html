x \to a

As x approaches a.



\lim_{x \to a} f(x) = c

As x approaches a, f(x) approaches c.
or
As x approaches a, the limit of f(x) is c.



\lim_{x \to a^-} f(x) = c

As x approaches a from the left, f(x) approaches c.



\lim_{x \to a^+} f(x) = c

As x approaches a from the right, f(x) approaches c.
